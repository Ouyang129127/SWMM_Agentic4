# 第二类简化：请求内的浅层静态共享

2026-11-15。诊断发送入口在第一类过程表格化之后，增加 `shallow_shared_v1` 视图。原始证据包、任务快照、数值、证据 ID 和引用校验保持原有结构。

## 共享范围

- 同一请求内全部记录明确属于同一模型和运行时，`source_model`、`run_id` 可移至 `record_defaults`。
- `local_structure.value.nodes` 中完全相同的已知节点输入定义。
- `local_structure.value.links` 与 `facilities_and_storage.value.local_facilities` 中完全相同的已知管段/设施输入定义。可在不同事件间共享，也可在同事件的结构与设施记录之间共享。
- 定义必须匹配对象类型、对象编号和全部 JSON 值。不同编号即使数值相同也分别处理；同编号的不同定义不会合并。比较区分整数、浮点数、布尔值、字符串、负零、`null` 和字段不存在。
- 仅处理已知静态字段。定义出现未知字段、过程字段、已有嵌套引用或不支持的对象类型时，保持内联。

事件事实、时间窗、对象列表、`topology_scope`、`structure_audit`（含 `event_interfaces`）、来源、单位、方法、设施动作与储量过程均留在各自记录中。未合并重叠过程窗口，未实施第三类事实归一或第四类跨轮工作集。

## 读取规则

```json
{
  "evidence_view_format": "shallow_shared_v1",
  "record_defaults": {"source_model": "Example1", "run_id": "R1"},
  "shared_static": {
    "S1": {"link_type": "CONDUITS", "from_node": "10", "to_node": "21", "length": 121.92}
  },
  "visible_evidence": [
    {"evidence_id": "E1", "event_id": "10:E001", "value": {"links": {"6": {"$ref": "S1"}}}},
    {"evidence_id": "E2", "event_id": "10:E002", "value": {"links": {"6": {"$ref": "S1"}}}}
  ]
}
```

示例省略了其他记录字段。对象定义只引用一次共享表；池内保存完整定义，不再引用其他条目。共享编号避开本请求实际证据 ID。

`record_defaults` 只补全记录缺少的模型和运行字段，记录显式值优先，显式 `null` 不视为字段缺少。转换器仅在所有记录原本均有相同的非空模型/运行字段时提取默认值，不填补原始缺失。

共享表不增加事件范围。模型只分析该事件记录对象映射列出的对象，仍引用 E1、E2 等原证据 ID；S1 等池编号不能用作证据引用。两个事件共享几何不等于共享事件过程。

## 长度与提示词

单条记录保持自包含；对重复定义先计算引用收益，再比较整个视图。最终检查计入格式标记、公共字段、共享表、引用，以及新增共享读取说明的字符开销。只有完整请求确实变短才启用共享，否则退回仅第一类表格化的表示。

新增读取说明仅在当前请求启用共享时追加。`diagnosis_system_prompt(prompt)` 统一决定实际系统提示词，模型发送、请求字符数、系统提示哈希及批量预估均使用它。该门槛保证字符量减少；实际 token 降幅仍需分词器或调用审计验证。

## 实现与验证

- `workflow_agents/diagnosis/shared_transport.py`：构建浅层共享视图，并提供 `restore_shared_evidence` 供检查还原。该函数只还原第二类共享，第一类过程表格保留。
- `workflow_agents/diagnosis/service.py`：统一组包与实际提示选择；输出校验继续使用原始可见记录。
- `tests/test_shared_transport.py`：JSON 往返、类型与缺失区分、事件范围、未知字段、设施、ID 冲突、提示开销，以及真实发送入口的模拟客户端、修订和引用校验。
- `outputs/shallow_shared_20261115/verification.json`：保存输入的只读还原与代理分词检查；未调用模型。

对Agentic3三组批量模拟的81份有用量记录的历史请求做只读配对回放，计入新增共享说明后，`cl100k_base`与`o200k_base`分别测得相对“仅第一类表格化”的聚合输入token数再减少4.784%和4.946%；81份请求均可还原，源审计与快照哈希保持一致。此处为代理分词计数的聚合比例，不是提供方真实用量复测，也未按历史提供方用量重新加权。

两份当前M6输入预览中，额外降幅分别约1.05%–1.15%和0.59%–0.67%；第二份没有足够重复静态定义，仅公共模型/运行信息产生共享收益。不同输入的收益取决于重复结构占比。此前第二类整套估算还包含更多共同来源、单位、方法及范围等信息共享，本版明确保留这些字段，不能直接套用此前较宽方案的降幅。

运行中的服务重启后加载新转换和提示。无须重新模拟或重建证据，历史记录保持不变。
